# 🎞️ 動画名人 🎞️

「動画名人」は、**スライドショー形式の動画**を簡単に作成できる Windows 用アプリです。画像と音声を組み合わせるだけで、ナレーション付きの動画を作成できます。

**[➡️ ホームページはこちら](https://yosukey.github.io/DougaMeijin)**

プログラミング知識や複雑な動画編集ソフトは必要ありません。動画作成初心者の方に向けたツールです。あえて機能を極限まで絞って、使いやすくしています。動画編集に不慣れでも、ちゃんと**名人**級の動画ができますよ！


⚠️アプリにはコード署名がされていません。従いまして、インストーラー開始時と、アプリ初回起動時にはWindowsのSmartScreenという青い背景のメッセージが表示されます。

---

## ✨ 主な機能（できること）

- **画像から動画を作成**  
  - PNG, JPG, BMP, WEBP, PDFに対応
- **ページごとの音声設定**
  - 1枚ごとに音声を録音するか、音声ファイルをドラッグ＆ドロップで追加する
- **プロジェクト保存・読み込み**  
  - 作業内容を `.dmj` プロジェクトとして保存

---

## 🚫 制限事項（できないこと）

- **動画クリップの編集は不可**  
  - 本アプリは「静止画像＋音声」によるスライドショー動画専用です。  
  - 動画素材の編集はできません。
- **高度な動画編集機能なし**  
  - テロップ挿入、BGM合成、その他高度な動画編集は非対応です。
- **Windows専用**  
  - macOS / Linux は動作確認していません。
- **録音環境依存**  
  - 録音の音質は接続しているマイクや環境ノイズに左右されます。録音後の調整もできません。
- **書き出し動画の設定**
  - H.264 + AAC 形式のMP4固定です。その他、動画のパラメーターの調節はできません。ほどほどのクオリティを保ち、なるべく互換性が高い設定で書き出します。また、動画作成の時短とファイルサイズの軽量化に重きを置いた書き出し動画設定をしています。
  - 解像度についても1080p（1920x1080）または720p（1280×720）のみが選択できます。いずれも横長16:9の動画です。

---

## 📥 インストールと起動

1. インストーラーを実行  
2. 初回起動時に **FFmpeg** のダウンロードを求められたら「はい」を選択  
3. 起動後、画像ファイルをドラッグ＆ドロップして新規プロジェクトを開始  

---

## 📖 使い方（手順）

1. 画像を追加する（ドラッグ＆ドロップ、または「画像を追加」ボタン）  
2. 各ページを選んで音声を録音する、または別途録音した音声ファイルをドラッグ＆ドロップする  
3. 録音内容を確認 
4. 完成したら「動画を書き出す」で MP4 ファイルを保存  

---

## 📖 動作の説明（ちょっと詳しく）

- 画像に対応した音声の時間が、そのままそのコマの再生長さとなります。
- 画像を読み込んだ後、ページ画像のドラッグ＆ドロップで順序入れ替えができます。
- 書き出し動画は画面比率16:9です。素材とする写真類は、必ずしも16:9のサイズではないでしょう。画像利用時には、はみ出しがないように16:9の動画にフィットされ、画面には余分（レターボックス；余黒）が設定されるようになっています。
- 読み込んだ各画像を右クリックするとロックができます。あやまって録音・設定済の音声を上書きしてしまわないようにするためのロックです。再度右クリックするとロック解除ができます。
- 録音ボタンのマウスクリックだけでなく、スペースキーで録音の開始と停止ができます。
- 録音した音声の末尾0.2秒を削除しています。ご承知おきください。録音終了ボタンを押したときのマウスクリック音を取り除くためです。
- 「録音デバイス」で、適切なマイクを選択してください。例えばノート型PCでは、内蔵マイクが備えられている場合が多くあります。その他に、外付けのマイクや、マイク内蔵ヘッドセット、をPCに接続されている方も多いと思います。それらのどれで録音するかを選択する、というオプション項目です。
- アプリ起動後に録音デバイスを追加（たとえばUSBマイクを接続）した場合は、「ツール」＞「録音デバイスを再スキャン」を実行すると、「録音デバイス」に反映され、選択できるようになります。
- 切り替え効果とは、画像間の切り替え視覚効果のことです。切替効果を選択すると、画像間に2秒が追加され、視覚効果が適用されます。したがって、切り替え効果を選択すると、作成する動画の長さが、[画像の枚数-1]x2秒だけ増加することになります。

## ❓ 想定される質問

**Q. BGM を入れることはできますか？**  

A. 本アプリはナレーション録音に特化しています。BGMの追加はできません。BGMを追加するのに、ナレーションのバックで実際に音楽を流すのはどうでしょう？またPCへの入力時にmixすることもできるでしょうが、ここでは説明しません。簡単操作を堅持するために、動画名人にBGM追加機能を実装する予定はありません。

**Q. 録音した音声が小さい/大きいのですが？**  

A. ご利用のマイク設定や環境に依存します。Windowsの「サウンド設定」で入力音量を調整してください。動画名人で音量を調整する機能はありません。

**Q. 無音のスライドを作ることができますか？**

A. 無音が必要な場合は、必要な長さだけ無音を録音してください。

**Q. 字幕（テロップ）を入れたり、チャプターを切ったりしたいです。**

A. たしかにそういう機能があれば便利だと思います。しかし、あえて多機能を目指さないところにこのアプリの存在意義を認めるところです。今後も機能追加の予定はありません。

**Q. 貼り付けた写真の向きが変だなあ。**

A. スマホ等で撮影した写真は、スマホを縦または横のどちらで撮影したかという、向きの情報を持っています。
アプリでは、それを読み取って自動で回転処理をしていますが、対応できない可能性があります。スマホが記録
した向き情報が実際の写真と食い違っている場合もあります。後から個別に画像を回転することは、動画名人アプリではできません。
他のアプリで回転処理をしてください。

**Q. 会社のPCやオフライン環境でも使えますか？**

A. はい、多くの場合で利用できます。ただし、一部機能に制限がかかる場合があります。
会社のネットワークなど、プロキシサーバーや特殊なセキュリティ設定がある環境、またはインターネットに接続していない環境では、初回起動時のFFmpegの自動ダウンロードや、アプリの新しいバージョンの確認に失敗する可能性があります。
